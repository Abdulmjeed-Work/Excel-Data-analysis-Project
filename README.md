# Excel-Data-analysis-Project
Coffee Sales Analysis – Excel
Project Overview

This project analyzes coffee sales data using Microsoft Excel. The goal is to identify sales trends, compare performance across countries and coffee types, and identify the top customers.

The project includes data cleaning, data preparation, formulas, Pivot Tables, charts, and an interactive dashboard.

The United States generated the highest sales.
